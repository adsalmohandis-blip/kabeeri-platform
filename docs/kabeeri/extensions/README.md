# KABEERI Extensions Governance Pack

This folder contains the active extension-update governance pack used by EXT_UPDATE tasks.

## Files

- `EXTENSION_UPDATE_RULES.md`: mandatory rules and evidence requirements.
- `EXTENSION_BUSINESS_ARCHITECTURE.md`: marketplace, monetization, audience, and trust model.
- `EXTENSION_TECHNICAL_ARCHITECTURE.md`: registry, manifest, review, signing, install/update, and rollback architecture.
- `EXTENSION_DATABASE_API_ADDENDUM.md`: schema and API addendum template.
- `EXTENSION_CODEX_PROMPT_PACK.md`: safe Codex prompts for future extension work.
- `EXTENSION_ACCEPTANCE_CHECKLIST.md`: release checklist for extension tasks.
- `MANIFEST.json`: machine-readable index for this governance pack.
