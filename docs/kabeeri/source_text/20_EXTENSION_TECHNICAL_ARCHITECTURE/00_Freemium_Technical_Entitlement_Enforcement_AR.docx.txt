KABEERI Freemium Technical Entitlement Enforcement
شرح تقني لكيفية فرض حدود الخطة المجانية والترقيات داخل Laravel بدون كسر V1.
Version: v1.6.4 | Status: Approved Documentation Addendum
هذا الملف جزء من تحديث Freemium & Plans ولا يغير ملفات V1 المجمدة مباشرة. أي تطبيق يتم عبر Addendum أو تاسك واضح في Codex.
الموقع داخل المعمارية
Freemium ليس مجرد Pricing Page. هو طبقة Entitlements يتم فحصها قبل إنشاء الموارد، تثبيت الثيمات/البلجنز، ربط الدومين، استخدام التخزين، واستخدام ميزات AI/Commerce/Marketing.
Feature Flags vs Entitlements
Feature Flags تتحكم في فتح/غلق ميزة على مستوى النظام أو التجربة. Entitlements تتحكم في حق العميل حسب خطته واشتراكه. لا يتم استخدام Feature Flag وحده لمنح ميزة مدفوعة.
نقاط الفحص في الكود
قبل إنشاء App/Site جديد.
قبل نشر صفحة جديدة إذا تجاوز حد الصفحات.
قبل رفع ملف جديد أو تجاوزه حد التخزين.
قبل تركيب Theme أو Plugin يتطلب خطة أعلى.
قبل إزالة Branding أو ربط Custom Domain.
قبل استخدام AI credits أو إرسال حملات تسويقية.
داخل Filament actions وداخل APIs العامة، وليس في الواجهة فقط.
الخدمات المقترحة
PlanResolverService, EntitlementService, UsageMeterService, UpgradeTriggerService, FairUseGuardService. كل خدمة تكون قابلة للاختبار ولا تعتمد على واجهة المستخدم.
