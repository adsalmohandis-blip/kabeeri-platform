1. الهدف
هذا الملف يضع جداول v1.1.0 داخل ترتيب Laravel migrations بطريقة لا تكسر Core Kernel ولا V1. لا يتم بناء كل الجداول في أول Sprint، لكن يتم تحديد مكانها المنطقي داخل waves.

3. أولويات V1 الفعلية
• Wave 0 إلى Wave 4 مطلوبة فعليًا لبدء V1.
• Wave 5 وWave 6 تدخل كـ foundation فقط بدون Marketplace كامل.
• Wave 7 تدخل كـ placeholder بسيط إن كان الوقت يسمح.
• Wave 10 وما بعدها لا تدخل في Sprint 1 إلا كـ migrations مؤجلة أو feature flags مغلقة.

5. Foreign Key Strategy
• Core tables تستخدم foreign keys حقيقية مع cascade/restrict محسوبة.
• Activity/Audit logs تستخدم nullable polymorphic references لتجنب كسر السجل عند حذف الكيان.
• جداول الحزم والـ recipes تستخدم soft references عبر package_key/version عند الحاجة.
• لا يتم عمل cascade delete لأي بيانات مالية أو توثيق أو اعتماد.
