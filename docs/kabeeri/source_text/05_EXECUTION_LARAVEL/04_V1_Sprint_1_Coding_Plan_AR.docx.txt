1. هدف Sprint 1
الخروج بنواة Laravel قابلة للتشغيل تحتوي Auth، Users، Organizations، Memberships، Roles/Permissions، Sites، Activity Log، Feature Flags، وأول Filament navigation بسيط.
2. المخرجات النهائية
• Laravel app يعمل محليًا.
• Filament admin مثبت ومؤمن.
• أول migrations الأساسية تعمل.
• Models وعلاقاتها الأساسية موجودة.
• Policies مبدئية لـ Organization/Site.
• Seeders لأدوار وصلاحيات V1.
• Filament Resources لـ Organizations, Sites, Users, Activity Logs.
• Feature tests تمر بنجاح.
• Git history صغير ومنظم.

6. أول Policies
• OrganizationPolicy: view, update, inviteMember, manageRoles.
• SitePolicy: view, create, update, delete, manageSettings.
• RolePolicy: assign only with users.role.assign permission.
• AuditLogPolicy: sensitive logs only for authorized admins.
7. Git Commit Plan
• chore: bootstrap laravel filament project
• feat: add identity and organization migrations

• feat: add sites settings and feature flags
• feat: add activity audit logs and notifications foundation
• feat: add initial filament resources
• test: add core identity and permissions tests
8. Acceptance Criteria
• User can login to Filament.
• Organization owner can create organization and site.
• Unauthorized user cannot manage another organization.
• Important actions create activity logs.
• Feature flags can be created and overridden.
• Tests pass and migrations refresh cleanly.
