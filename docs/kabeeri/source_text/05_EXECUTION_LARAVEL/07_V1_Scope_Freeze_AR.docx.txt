1. قرار التجميد
V1 ليس نسخة Kabeeri الكاملة. V1 هدفه بناء نواة قابلة للتوسع: مستخدم، منظمة، تطبيق، CMS، Media، Themes basic، Package foundation، Import foundation، وصلاحيات. أي ميزة لا تخدم هذا الهدف تؤجل.
