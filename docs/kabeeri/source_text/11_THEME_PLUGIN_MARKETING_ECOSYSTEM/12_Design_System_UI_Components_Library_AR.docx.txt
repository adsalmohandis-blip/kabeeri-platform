12 — Design System ومكتبة UI Components
هذا الملف يحكم الشكل الموحد للثيمات حتى لا تتحول الـ 300 ثيم إلى تصميمات عشوائية أو متضاربة.
Version: v1.6.3 — Theme & Plugin Ecosystem Completion
قاعدة التحديث: هذا الملف يضيف تفاصيل تنفيذية جديدة ولا يغير ملفات V1 المجمّدة. أي ربط مع ملفات سابقة يتم بالإشارة فقط.
Design Tokens الأساسية
Colors: primary, secondary, accent, neutral, success, warning, danger.
Typography: Arabic-first, fallback English, heading/body/label scales.
Spacing: نظام موحد للحواف والمسافات.
Radius/Shadow: مستويات ثابتة للبطاقات والأزرار.
RTL/LTR: كل component يجب أن يدعم الاتجاهين.
Accessibility: contrast, focus states, semantic HTML.
