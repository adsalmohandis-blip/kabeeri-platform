5. Package Manifest Rules
name, slug, type, version, publisher, dependencies, permissions, data scopes, events, hooks, compatibility, pricing, review_status, signature
• كل حزمة تعلن required/recommends/conflicts/extends/provides.
• كل حزمة تعرض صلاحياتها قبل التثبيت.
• ERP Modules تحتاج مراجعة أعلى من Plugins العادية.
• أي حزمة لها migrations تحتاج backup وrollback plan.
