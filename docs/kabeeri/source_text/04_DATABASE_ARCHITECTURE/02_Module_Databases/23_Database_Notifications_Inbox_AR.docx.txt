1. الهدف
Notification Center وUnified Inbox هما طبقتان مركزيتان تخدمان CMS وRabet وCommerce وERP وMall وAI وSecurity. لا يجوز لكل module أن يبني نظام إشعارات منفصل.

5. Flows
• Service request → conversation created → business notified → optional CRM lead.
• Verification request assigned → legal partner sees only assigned conversation and documents.
• Dispute opened → dispute conversation locks participants and evidence access.
• AI suggests reply → preview → user approves before sending.
6. Privacy Rules
• Inbox is context-first and permission-aware.
• Private employee evaluations do not appear in public/talent inbox.
• Legal documents require sensitive access logs.
• Portable export includes only tenant conversations allowed by retention policy.
