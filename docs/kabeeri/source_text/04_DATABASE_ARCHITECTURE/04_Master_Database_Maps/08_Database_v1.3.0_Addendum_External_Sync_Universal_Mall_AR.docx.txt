3. قواعد Source of Truth
البيانات التشغيلية الأصلية تبقى في مصدرها: Kabeeri App أو External System أو Backoffice.
Kabeeri Mall يعرض فقط Mall Mirror/Public Mirror بعد موافقة ونشر ومراجعة.
External connector لا يملك صلاحية افتراضية للوصول للطلبات أو العملاء أو البيانات المالية الخاصة.
Backoffice Anywhere يمكن أن يكون مصدر إدارة داخلي، لكن النشر العام يمر عبر catalog consent.
4. إدراج في Migration Waves
V2: external_sync_sources, mall_catalogs, catalog_publication_consents. V3: courses/trips mirrors, backoffice_connections. V4: jobs/projects, partners, events/deals. V5: RFQ/assets and advanced sync records. V6: connector marketplace and custom SDK tables.
