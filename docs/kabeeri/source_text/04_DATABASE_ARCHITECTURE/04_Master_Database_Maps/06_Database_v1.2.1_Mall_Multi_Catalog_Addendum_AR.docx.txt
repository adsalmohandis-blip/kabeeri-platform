1. الهدف
هذا الملحق لا يستبدل ملف Mall Public Marketplace Database، بل يوسعه ليحول Kabeeri Mall إلى شبكة كتالوجات عامة: منتجات، خدمات، بزنسز/مشاريع، مواهب، وثيمات/إضافات. الملحق يراعي أن المصدر قد يكون Cloud أو Frontend Anywhere أو Portable أو Dedicated أو WordPress خارجي.
2. مبدأ عدم التكرار
لا نكرر mall_mirror_products أو mall_mirror_services أو mall_mirror_businesses إذا كانت موجودة. نضيف طبقة catalog/channel/source تربط هذه الجداول بتجربة المول العامة، ونضيف جداول جديدة فقط حيث توجد فجوة حقيقية مثل App/Project public listings.

8. تحديثات على الجداول الموجودة
الجدول الموجود
التعديل المقترح
mall_sync_sources
إضافة source_type=external_wordpress وsource_mode=plugin_push/feed_pull عند الحاجة.
mall_publication_consents
إضافة consent scopes: product_mall, service_mall, business_mall, project_mall, partner_storefront_share.
mall_mirror_products
إضافة fulfillment_owner_type وfulfillment_owner_id وsource_public_url إن لم تكن موجودة.
mall_mirror_services
إضافة request_mode: contact/booking/quote/external_redirect.
mall_mirror_businesses
إضافة business_mall_enabled وprimary_app_listing_id nullable.
external_site_connections
إضافة connection_type=external_wordpress_mall_source إن لم يكن موجودًا.

10. Acceptance Rules
القاعدة
شرط القبول
No private data
أي record في mirror لا يحتوي بيانات عملاء/طلبات/تكاليف داخلية.
Consent required
كل item published يجب أن يرتبط بموافقة أو rule واضح.
Source traceability
كل item يعرف مصدره: Cloud/Portable/Dedicated/WordPress/manual.
Moderation ready
كل item يقبل publication_status وتغييرات moderation.
Rebuildable mirror
يمكن حذف وإعادة بناء mirror من المصدر بدون فقد source of truth.
