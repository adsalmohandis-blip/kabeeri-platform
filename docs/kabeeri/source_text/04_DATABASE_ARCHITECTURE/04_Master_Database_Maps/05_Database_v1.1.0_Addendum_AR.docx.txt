1. هدف هذا الملحق
هذا الملحق يحول توسعات v1.1.0 إلى جداول تنفيذية واضحة قبل كتابة migrations. لا يستبدل ملفات الداتابيز السابقة، بل يضيف طبقة Coding-ready فوقها حتى لا تضيع كيانات Work Network وAcademy وAffiliate وTheme Recipes وMarketing Suite أثناء التنفيذ.
• كل جدول جديد يجب أن يكون tenant-scoped عند الحاجة عبر organization_id.
• كل كيان يظهر للعامة يجب أن يحترم visibility وpublication_status.
• كل قدرة مهنية أو شراكة لا تفتح إلا بعد Academy / verification / approval حسب النوع.
• كل عمولة أو إحالة يجب أن تمر عبر attribution event قابل للتدقيق.

9. قواعد التنفيذ
• أي جدول جديد له بيانات عميل يجب أن يحتوي organization_id أو يرتبط بسجل يحتويه.
• أي جدول public profile يجب أن يحتوي visibility وpublication_status.
• أي token أو رابط إحالة لا يخزن secret كنص واضح؛ نخزن hash أو code آمن.
• أي payout أو commission لا يصبح payable قبل انتهاء hold_period وrefund window.
• أي theme/package recipe لا يثبت حزمة مدفوعة بدون entitlement check واضح.
