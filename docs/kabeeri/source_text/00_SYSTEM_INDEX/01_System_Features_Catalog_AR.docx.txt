ملاحظات تنفيذية
• هذا الملف لا يستبدل ملفات الداتابيز أو الـ Laravel Build Order؛ بل يلخص الخصائص على مستوى المنتج.
• المرحلة V1 يجب أن تبقى محدودة: Core، Users، Organizations، Apps/Sites، CMS، Media، Themes basic، Package foundation، Onboarding، وWordPress migration foundation.
• كل خاصية مرتبطة بـ Plans / Entitlements / Feature Flags قبل تفعيلها تجاريًا.
• أي خاصية تتعامل مع بيانات حساسة أو أموال أو توثيق أو AI write actions يجب أن تمر عبر RBAC وAudit Logs وApprovals.
• Theme Store وPlugin Store وWork Network وAcademy هي محركات نمو وتسويق، لكنها تُفتح تدريجيًا بعد استقرار الأساس.
