قاعدة البرومبتات
برومبتات المنصة الأساسية V1–V6 في فولدر واحد فقط: 16_CODE_PROPMPTS_TO_CREATE_BY_CODEX. برومبتات أي تحديث أو إضافة لاحقة في فولدر واحد فقط: 22_EXTENSION_CODEX_PROMPTS.
قاعدة التحديثات
أي ميزة جديدة يجب أن تضاف كحزمة ملفات: Business, Technical, Database/API, Codex Prompt Pack, Acceptance Checklist. لا يتم خلط هذه الملفات مع ملفات V1 المجمدة إلا عبر Addendum واضح.
