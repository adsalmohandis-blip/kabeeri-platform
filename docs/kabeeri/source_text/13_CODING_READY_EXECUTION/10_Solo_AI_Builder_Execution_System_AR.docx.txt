KABEERI Solo AI Builder Execution System
نظام تنفيذ مرن لشخص واحد يعمل بالذكاء الاصطناعي — v1.6.5
1. الغرض من الملف
هذا الملف يحوّل تنفيذ KABEERI من خطة زمنية ثابتة إلى نظام تنفيذ مرن مناسب لشخص واحد يعمل بمساعدة Codex/ChatGPT. لأن وقت العمل اليومي غير ثابت، يعتمد النظام على بطاقات مهام صغيرة بدل سبرنتات إلزامية بالأيام.
2. القاعدة الذهبية
One prompt → one branch → one small feature → tests → review → commit.
لا يتم تنفيذ أكثر من Prompt في نفس الوقت. لا يتم فتح V2 قبل استقرار V1. لا يتم إدخال Mall أو Commerce أو Freemium أو V7/V8 داخل V1 إلا إذا كان ذلك ضمن Prompt صريح ومجمد.

5. دورة الجلسة القياسية
• افتح WORKLOG.md واعرف آخر Prompt مكتمل.
• افتح ملف V1 Codex Prompt Pack ولا تختار إلا Prompt واحد.
• أنشئ branch جديد باسم واضح مثل feature/v1-organizations.
• شغّل Codex على الـ Prompt فقط، مع قواعد V1.
• راجع الملفات المتغيرة قبل قبولها.
• شغّل php artisan test وvendor/bin/pint عند الحاجة.
• اكتب ملخص في WORKLOG.md.
• اعمل commit واحد واضح.
• لا تبدأ Prompt جديد إلا بعد commit.
