1. قواعد استخدام لوحة المهام
هذه اللوحة لا تستبدل ملف V1 Codex Prompt Pack، بل تترجمه إلى بطاقات تنفيذ مرنة حسب الوقت المتاح. عند تنفيذ أي بطاقة، استخدم الـ Prompt المقابل من ملف V1 الأصلي ولا تدمج بطاقتين في نفس الجلسة إلا إذا كان لديك يوم كامل وبعد commit منفصل لكل بطاقة.
