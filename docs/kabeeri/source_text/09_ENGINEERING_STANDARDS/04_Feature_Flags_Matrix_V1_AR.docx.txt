3. قواعد الاستخدام
• كل module جديد له flag قبل أي UI.
• لا يكفي flag إذا كانت الميزة مدفوعة؛ يجب entitlement check أيضًا.
• Feature flag لا يتجاوز permissions.
• Flags الخاصة بالـ Platform لا يراها العميل.
• Seed default flags في بيئة التطوير يمكن أن تختلف عن production.
