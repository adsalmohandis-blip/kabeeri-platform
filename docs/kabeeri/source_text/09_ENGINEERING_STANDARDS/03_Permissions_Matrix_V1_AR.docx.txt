4. قواعد Policies
• لا تعتمد على role فقط؛ افحص permission + membership + scope.
• أي action critical يحتاج audit log.
• أي action يثبت package أو يغير permissions يحتاج confirmation وربما backup.
• Agency/App Builder access يكون مؤقتًا ومحددًا بالـ scope.
• Deny override يتغلب على allow.
