1. القرار التنفيذي
Kabeeri Mall ليس مولًا واحدًا فقط، بل شبكة اكتشاف عامة Multi-Catalog تعرض المنتجات والخدمات والبزنسز/المشاريع المتاحة عبر كل تطبيقات Kabeeri، سواء كانت مستضافة داخل Kabeeri Cloud أو Frontend Anywhere أو Portable أو Dedicated أو مصدر خارجي مثل WordPress.
القاعدة الحاكمة: المول لا يقرأ مباشرة من قواعد بيانات العملاء أو المواقع الخارجية. كل شيء يظهر في المول عبر Mall Mirror + Publication Consent + Sync Source.

3. نطاق Product Mall
Product Mall يعرض المنتجات المنشورة بموافقة التاجر من أي تطبيق مشترك في المنصة أو متصل بها. المنتج يبقى مملوكًا للتاجر الأصلي، والمول يعرض نسخة عامة فقط: الاسم، الصور، السعر العام، التوفر، رابط الشراء أو الطلب، وبيانات الثقة.

4. نطاق Service Mall
Service Mall يعرض الخدمات من الشركات، المهنيين، الوكالات، ومقدمي الخدمات. الطلب قد يكون Lead أو Service Request أو Booking حسب نوع الخدمة. التنفيذ دائمًا عند مقدم الخدمة الأصلي، وليس عند المول.

5. نطاق Business & Projects Mall
هذا المول يعرض البزنسز والمشاريع والتطبيقات العامة. المقصود بالمشروع هنا قد يكون: بزنس موثق، تطبيق موقع/متجر، مشروع وكالة، ملف شركة، أو جهة تعرض نفسها كشريك/مزود خدمة. هذه الطبقة هي واجهة الاكتشاف العامة لـ Rabet + Kabeeri Apps.

6. دعم التطبيقات الخارجية مثل WordPress
يمكن لموقع WordPress أو أي موقع خارجي أن يشارك منتجاته أو خدماته أو بروفايله العام في Kabeeri Mall بشرط وجود Connector أو Feed أو API آمن، وموافقة نشر واضحة. لا يتم سحب بيانات خاصة أو تشغيلية من WordPress.

7. قواعد النشر والموافقة
القاعدة
التفسير
Consent before publication
لا يظهر منتج أو خدمة أو بزنس في المول بدون موافقة نشر محددة.
Mirror only
المول يعرض نسخة عامة قابلة لإعادة البناء ولا يمثل source of truth.
Source owner remains owner
التاجر أو مقدم الخدمة هو المسؤول عن السعر، التوفر، التنفيذ، الشحن، الدعم.
Moderation first
أي محتوى عام قابل للبلاغ والمراجعة والإخفاء.
No private data
لا فواتير خاصة، لا عملاء، لا مخزون داخلي، لا مستندات حساسة.
8. تجربة المستخدم داخل المول
واجهة Kabeeri Mall يجب أن تعرض تبويبات واضحة: منتجات، خدمات، بزنسز/مشاريع، مواهب، ثيمات وإضافات. كل تبويب له فلاتر مختلفة، لكن كلها تعتمد على نفس مبادئ الثقة والموافقة والمصدر.

9. علاقة المول بالمسوقين والشركاء
Growth Partners وPartner Storefronts يمكنهم عرض منتجات وخدمات تجار آخرين فقط عبر اتفاقيات وموافقات واضحة. الواجهة الخاصة بالمسوق تعرض public mirror items، والطلب أو التنفيذ يذهب للتاجر الأصلي مع tracking للعمولة.
