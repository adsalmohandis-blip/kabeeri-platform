KABEERI Backoffice Anywhere Architecture
استخدام النظام الإداري في Kabeeri لإدارة بزنس أو موقع أو متجر موجود خارج Kabeeri دون نقل الواجهة أو الدومين.
إصدار الحزمة: v1.3.0 — Coding Ready Final
ملاحظة: هذا الملف جزء من KABEERI Professional Knowledge System ويستخدم كمرجع تنفيذي مباشر قبل وأثناء التكويد.
1. التعريف
Backoffice Anywhere يعني أن العميل قد يظل على موقعه الحالي WordPress أو WooCommerce أو Shopify أو Custom، لكنه يستخدم Kabeeri لإدارة CRM، المنتجات، الخدمات، الكورسات، الحجوزات، التسويق، التقارير، Rabet، والمزامنة مع Kabeeri Mall.
2. لماذا مهم؟
يقلل مقاومة العملاء الذين لا يريدون نقل موقعهم فورًا.
يفتح قناة بيع Kabeeri كأداة إدارة وتشغيل وليس مجرد منشئ مواقع.
يمهد للهجرة لاحقًا عندما يثق العميل في النظام.
يسمح بظهور منتجات وخدمات وكورسات العميل في Kabeeri Mall من مصدر خارجي أو إداري.
3. الموديولات الممكن استخدامها

4. قواعد الأمان
أي اتصال خارجي يستخدم tokens مشفرة أو refs إلى Vault وليس أسرار واضحة.
لا يتم مزامنة بيانات خاصة إلى المول.
يجب فصل صلاحيات Backoffice عن صلاحيات الموقع الخارجي.
كل مزامنة تسجل في sync logs وتخضع للـ consent.
