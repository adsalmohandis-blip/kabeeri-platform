1. دور Academy
Kabeeri Academy هي مصدر الثقة والاعتماد للوظائف الجديدة داخل المنصة. لا يمكن لأي شخص تقديم خدمة حساسة باسم Kabeeri إلا بعد إتمام المسار المناسب.
Learning Path → Lessons → Quiz → Practical Task → Review → Badge → Capability Enabled → Level Progression

• تربط Talent Marketplace بالاعتماد المهني.
