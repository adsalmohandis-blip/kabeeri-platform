KABEERI Work Network Roles & Capabilities Matrix
مصفوفة الوظائف والقدرات داخل منظومة كبيري، مع توزيعها على Talent Marketplace وWork Network وCreator Network وAgency وRabet.
إصدار الحزمة: v1.3.0 — Coding Ready Final
ملاحظة: هذا الملف جزء من KABEERI Professional Knowledge System ويستخدم كمرجع تنفيذي مباشر قبل وأثناء التكويد.
1. القاعدة الحاكمة
كل مستخدم له User واحد فقط، ويمكن أن يفعّل أكثر من Capability على ملفه العام بعد التعليم والاختبار والاعتماد.
Talent Marketplace عام للمواهب ولا يعني أن الشخص معتمد للعمل داخل Kabeeri Work Network.
Work Network يضم الوظائف المرتبطة بتنفيذ وتسويق ودعم ونمو تطبيقات Kabeeri.
Agency Partner كيان مؤسسي له فريق وDashboard واعتماد سنوي، وليس مجرد لقب شخصي.
