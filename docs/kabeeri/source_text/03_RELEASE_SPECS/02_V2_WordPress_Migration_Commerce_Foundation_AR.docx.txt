KABEERI V2 — WordPress Migration + Commerce Foundation
الإصدار الثاني من منصة KABEERI / Kabeeri / kabeeri — powered by ADMIT
هذا الملف يشرح V2 بالتفصيل بعد بناء V1.
V2 هو الإصدار الذي يبدأ نقل Kabeeri من مجرد CMS قوي للشركات إلى منصة تستطيع جذب جمهور WordPress وWooCommerce، مع بداية Commerce وBusiness Directory وService Listings.
الرسالة التنفيذية لـ V2:
Kabeeri V2 يجعل الانتقال من WordPress ممكنًا، ويضيف أساس التجارة والخدمات بحيث يبدأ الموقع في استقبال عملاء وطلبات حقيقية.
1. هدف V2
1.1 الهدف التقني
بناء طبقة استيراد وهجرة من WordPress، وتوسيع CMS، وإضافة Commerce Foundation، ونماذج Forms، وبداية Business Directory وService Listings.
1.2 الهدف التجاري
إقناع جمهور WordPress أن Kabeeri ليس مجرد فكرة جديدة، بل يمكنه استقبال مواقعهم الحالية ونقل محتواهم، ثم منحهم مسارًا للمتجر والخدمات والعملاء.
1.3 هدف المنتج
V2 يجب أن يثبت 3 وعود:
1. يمكنك نقل موقع WordPress إلى Kabeeri.2. يمكنك إنشاء متجر بسيط واستقبال Orders.3. يمكنك عرض بزنس وخدمات واستقبال Service Requests.
2. V2 يبني على ماذا؟
V2 لا يبدأ من الصفر.

5. رسالة V2 التسويقية
5.1 للجمهور العام
انقل موقعك من WordPress، وابدأ في تحويله إلى موقع أعمال حقيقي يستقبل طلبات وخدمات ومنتجات.
5.2 لجمهور WordPress
Kabeeri V2 يعطيك طريق انتقال من WordPress بدون فقد المحتوى والـ SEO، مع أساس أنظف للنمو.
5.3 لأصحاب الشركات
موقعك لم يعد مجرد صفحات؛ يمكنك الآن استقبال طلبات خدمات، عرض منتجات، وبناء قاعدة عملاء.

8. V2 User Stories
8.1 نقل موقع WordPress
As a site ownerI want to upload a WordPress export fileSo I can migrate my pages, posts, categories, tags, and media into Kabeeri.
8.2 تقرير الهجرة
As a site ownerI want to see a migration reportSo I know what was imported, what failed, and what needs review.
8.3 إنشاء منتج
As a store managerI want to create a product with price, SKU, image, and stockSo visitors can buy it.
8.4 شراء منتج
As a customerI want to add a product to cart and place an orderSo I can buy from the business.
8.5 إدارة الطلبات
As a business ownerI want to see orders and update their statusSo I can fulfill customer purchases.
8.6 عرض الخدمات
As a business ownerI want to list my servicesSo visitors can request them.
8.7 طلب خدمة
As a visitorI want to request a serviceSo the business can contact me.
8.8 إدارة مهمة
As a team memberI want to receive and complete tasksSo the company can organize basic work.

35. AI Build Prompts لـ V2
35.1 WordPress Parser
ابني WordPressXmlParser في Laravel يقرأ ملف XML ويستخرج posts/pages/categories/tags/attachments بدون حفظ في قاعدة البيانات. أرجع DTOs واضحة واكتب tests.
35.2 Migration Report
ابني MigrationReportBuilder يأخذ import_job_id ويجمع عدد imported/failed/warnings لكل source_type ويخرج summary JSON.
35.3 Product CRUD
ابني Filament Resource للمنتجات يدعم name, slug, sku, price, sale_price, stock_quantity, status, featured image, categories.
35.4 Cart Service
ابني CartService يحتوي addProduct, updateQuantity, removeItem, calculateTotals، ولا يثق بأي سعر من frontend.
35.5 Checkout
ابني CheckoutAction يأخذ cart_id وبيانات العميل ويعيد Order مع OrderItems محسوبة server-side.
35.6 Service Request
ابني SubmitServiceRequestAction ينشئ service_request ويرسل notification لصاحب البزنس ويسجل activity log.

41. أخطاء ممنوعة في V2

41.3 لا تستورد بدون Preview
الهجرة بدون preview خطر.
41.4 لا تهمل redirects
SEO مهم لجمهور WordPress.
41.5 لا تجعل Customer = User دائمًا
Customer قد يكون guest.
41.6 لا تنفذ imports داخل request مباشر
استخدم queues.
41.7 لا تبني inventory ledger كامل في V2
هذا يدخل V3.
41.8 لا تفتح Kabeeri Mall كامل
V2 فقط Business Directory وServices foundation.
