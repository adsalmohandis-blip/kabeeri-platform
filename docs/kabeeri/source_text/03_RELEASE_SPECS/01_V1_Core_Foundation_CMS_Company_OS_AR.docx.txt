KABEERI V1 — Core Foundation for CMS + Company OS
الإصدار الأول من منصة KABEERI / Kabeeri / kabeeri — powered by ADMIT
هذا الملف هو أول ملف تنفيذي حقيقي بعد الملف الرئيسي والملاحق التأسيسية.
V1 ليس الهدف منه بناء كل Kabeeri.
V1 هدفه بناء الأساس الذي لا يمكن أن تقوم المنصة بدونه:
CMS قوي+ Organizations+ Sites+ Company foundation+ Permissions+ Media+ Themes+ Plugins basic+ Activity Log+ Business Profile draft+ Verification foundation+ Notifications basic+ Feature Flags+ Onboarding basic
الرسالة التنفيذية لـ V1:
Kabeeri V1 هو CMS جديد للشركات، مبني من البداية ليتحول لاحقًا إلى Rabet وCommerce وERP وKabeeri Mall، وليس مجرد WordPress clone.
1. هدف V1
1.1 الهدف التقني
بناء نواة Laravel مستقرة يمكن استخدامها لإدارة موقع شركة بسيط، مع بنية بيانات وصلاحيات تسمح بإضافة Rabet وCommerce وERP وKabeeri Mall لاحقًا بدون إعادة بناء جذرية.
1.2 الهدف التجاري
إطلاق نسخة يمكن عرضها كبديل حديث لـ WordPress للشركات الصغيرة والوكالات، مع رسالة واضحة:
ابدأ بموقع، ثم كبر إلى شركة رقمية متكاملة.
1.3 الهدف التجريبي
في نهاية V1 يجب أن نستطيع بناء Demo لشركة خدمات صغيرة تحتوي على:
موقع رسمي.
صفحات.
مقالات.
ميديا.
SEO.

أعضاء فريق.
صلاحيات.

2. ما هو V1؟
V1 هو:
Core Foundation for CMS + Company OS
يعني:
المستخدم يرى CMS بسيط ومنظم.

7. V1 User Stories
7.1 صاحب شركة يريد إنشاء موقع
As a business ownerI want to register and create an organization and siteSo I can publish my company website
7.2 محرر يريد إنشاء صفحة
As an editorI want to create and publish pagesSo visitors can see company content
7.3 صاحب موقع يريد رفع صور
As a site adminI want to upload mediaSo I can use images in pages and posts
7.4 صاحب شركة يريد تجهيز بروفايل بزنس
As a business ownerI want to create a business profile draftSo I can later appear in Kabeeri Mall
7.5 صاحب شركة يريد دعوة عضو فريق
As an organization ownerI want to invite a team memberSo they can help manage the site
7.6 المدير يريد رؤية النشاط
As an adminI want to see activity logsSo I know who changed what
