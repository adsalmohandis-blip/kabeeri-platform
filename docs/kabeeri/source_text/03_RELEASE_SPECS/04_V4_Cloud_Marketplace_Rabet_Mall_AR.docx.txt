KABEERI V4 — Cloud + Marketplace + Rabet Company OS + Kabeeri Mall
الإصدار الرابع من منصة KABEERI / Kabeeri / kabeeri — powered by ADMIT
هذا الملف يشرح V4 بالتفصيل بعد بناء V1 وV2 وV3.
V4 هو الإصدار الذي ينقل Kabeeri من منصة يمكن استخدامها داخليًا أو self-hosted إلى منتج تجاري قابل للبيع والتوسع:
Kabeeri Cloud+ Billing+ Internal Marketplace+ Rabet Company OS V1+ Legal Partner Network V1+ Kabeeri Mall V1+ Talent Marketplace V1+ Agency Platform+ Teams V1+ AI Co-builder V1+ Security Center
الرسالة التنفيذية لـ V4:
Kabeeri V4 يحوّل المنصة إلى Business Ecosystem قابل للبيع: استضافة، اشتراكات، توثيق، سوق داخلي، سوق عام، شركاء قانونيون، وكالات، فرق، وAI آمن للبناء.

1.3 هدف المنتج
V4 يجب أن يثبت 7 وعود:
1. يمكن إنشاء موقع Kabeeri Cloud.2. يمكن الاشتراك في خطة ودفع أو إدارة billing.3. يمكن تثبيت Package رسمي من Marketplace داخلي.4. يمكن شركة أن تتوثق عبر Legal Partner.5. يمكن Business أن يظهر في Kabeeri Mall.6. يمكن Professional أن يظهر في Talent Marketplace.7. يمكن AI أن يبني صفحات/forms/dashboards بعد Plan + Preview + Approval.

5.1 للشركات
Kabeeri V4 لا يبني موقعك فقط؛ بل يستضيفه، يوثّق شركتك، يظهرها في Kabeeri Mall، ويدير فريقك وطلباتك من منصة واحدة.

8. V4 User Stories
8.1 إنشاء موقع Cloud
As a business ownerI want to create a Kabeeri Cloud siteSo I can launch without managing hosting.
8.2 إدارة اشتراك
As an organization ownerI want to subscribe to a planSo I can unlock cloud, commerce, Rabet, or marketplace features.
8.3 تثبيت Package رسمي
As a site adminI want to install an official plugin or themeSo I can extend my site safely.
8.4 مراجعة صلاحيات Package
As an adminI want to see package permissions before installingSo I know what data it can access.
8.5 توثيق شركة عبر مكتب محاماة
As a company ownerI want my verification request reviewed by an accredited legal partnerSo my company can become verified.
8.6 مكتب محاماة يراجع طلب توثيق
As a legal partner userI want to view assigned verification requests onlySo I can review documents securely.
8.7 الظهور في Kabeeri Mall
As a verified or approved businessI want to publish my business and services in Kabeeri MallSo customers can discover and contact me.
8.8 Professional يستقبل عرض عمل
As a professionalI want to publish my profile with privacy controlsSo verified companies can send me job offers.
8.9 وكالة تدير مواقع عملائها
As an agencyI want a dashboard for all client sitesSo I can manage updates, status, and support from one place.
8.10 فريق يتواصل داخل Kabeeri
As a team memberI want channels and direct messagesSo I can collaborate without leaving Kabeeri.
8.11 AI يبني صفحة بعد موافقة
As a site adminI want AI to create a page draft and show a previewSo I can approve before publishing.

14. Kabeeri Cloud V1
14.1 Cloud Provisioning Flow
User chooses plan→ Create billing account/subscription→ Create organization/site→ Create cloud_site record→ Reserve subdomain→ Apply default theme→ Create default pages→ Run health check→ Site becomes active
14.2 Domain Flow
Add custom domain→ Show DNS instructions→ Verify DNS→ Issue SSL or mark pending→ Set primary domain→ Cache domain → site_id
14.3 Backup Flow
Create backup request→ Queue backup job→ Backup database/site files→ Store record→ Notify user
14.4 لا يدخل في V4
Auto-scaling full.
Multi-region.
Enterprise DR.
Complex Kubernetes.
