1. القاعدة الحاكمة
لا يتم تشغيل كود WordPress PHP داخل Kabeeri. يتم اكتشاف البلجنات والثيمات، تصنيفها، تحويل إعداداتها أو بياناتها عند الإمكان، ثم استبدالها بميزات أصلية أو Packages رسمية أو adapters أو skeletons تحتاج مراجعة.
2. Plugin Compatibility Statuses
الحالة

يتم منعه أو يحتاج مراجعة أمنية صارمة

4. Theme Migration Levels
• Level 1: Preserve Content + Apply Kabeeri Starter Theme.
• Level 2: Visual Approximation عبر استخراج logo/colors/fonts/header/footer/menus.
• Level 3: Generate Kabeeri Theme Draft من assets والقوالب الآمنة.
• Level 4: AI Rebuild للصفحات والثيم بعد visual comparison وموافقة المستخدم.

6. Licensing Rules
• تحويل theme/plugin لموقع العميل لا يعني السماح بنشره في Kabeeri Marketplace.
• أي نشر عام يحتاج license review، publisher identity، security scan، performance scan، RTL/responsive check، signing، وmanual review.
• لا يتم نسخ assets تجارية أو fonts أو images إلى Marketplace بدون تصريح واضح.
7. Marketplace Pipeline
• Generated skeleton starts as private draft.
• Developer/Agency reviews code and manifest.
• Permissions are declared explicitly.
• Security and compatibility scans run.
• Only approved and signed packages can be published.
