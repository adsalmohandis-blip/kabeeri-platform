1. الهدف
هدف Migration Center ليس استيراد بيانات فقط، بل نقل الموقع كأصل تجاري للعميل: المحتوى، الميديا، الروابط، الهوية البصرية، إعدادات SEO، وتجربة الانتقال الآمن إلى Kabeeri.
2. وعد المنتج
انقل موقعك من WordPress إلى Kabeeri بدون خسارة موقعك، ثم احصل على نسخة أسرع وأنظف وأكثر أمانًا وقابلة للنمو إلى Commerce وRabet وCompany OS.

4. خط سير الهجرة
• Upload / Connect WordPress site.
• Create migration_job and source snapshot.
• Analyze content, media, links, SEO, plugins, theme, and risk.
• Generate Migration Readiness Score.
• Import into staging, not production.
• Run visual comparison and SEO checks.
• Generate redirect map and warnings.
• User reviews and approves.
• Go Live with monitoring and rollback point.

6. حفظ المظهر Visual Preservation
• Preserve Look: استخراج الشعار، الألوان، الخطوط، القوائم، الهيدر والفوتر، ومحاولة توليد Kabeeri Theme Draft.
• Improve Look: نقل المحتوى مع تطبيق Kabeeri Theme حديث يحافظ على الهوية ويحسن الأداء.
• AI Rebuild: إعادة بناء الصفحة بنفس المحتوى لكن بتقسيم أفضل، CTA أوضح، وتحسين SEO بعد موافقة المستخدم.
7. حفظ SEO والروابط
• Preserve slugs where possible.
• Create redirects for changed URLs.
• Import SEO title and description from known SEO plugins when possible.
• Detect broken internal links after import.
• Generate migration report before Go Live.
• Keep old URL to new URL mapping forever unless removed deliberately.
