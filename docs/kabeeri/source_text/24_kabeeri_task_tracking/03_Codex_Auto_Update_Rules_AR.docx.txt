قواعد تحديث Codex التلقائي
القواعد التي تمت إضافتها إلى ملفات البرومبت
قبل بداية التاسك
يشغّل Codex أمر start برقم النسخة والتاسك.
بعد الانتهاء
يشغّل Codex أمر done مع رقم البرومبت ونتيجة الاختبارات وملخص.
عند التعطل
يشغّل Codex أمر block مع سبب واضح.
ما لا يفعله Codex
لا يعلّم التاسك verified ولا يغيّر نسخ مستقبلية إلا إذا كان البرومبت مخصصًا لها.
